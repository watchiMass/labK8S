Lab helper (local)

ReadMe

This is a local training recreation of the CKA ExamUI. The remote desktop is an XFCE Linux machine with a terminal, Firefox, VSCodium and a virtual keyboard.

Environment

  • The terminal runs on the base node. The prompt should read candidate@base:~$.
  • Use ssh node01 and ssh node02 for worker tasks.
  • The lab repository is at ~/cka-practice-labs.

Keyboard

The desktop starts in French AZERTY. The real exam uses US QWERTY. Switch with the keyboard icon in the top panel or cka-keyboard us. Use cka-keyboard fr to switch back.

Copy and paste

Select a command or use a “Copy to desktop” button, then paste in the remote terminal with Ctrl+Shift+V. Inside the terminal, Ctrl+Shift+C copies.

Docs

Firefox is restricted to kubernetes.io by default, as in the exam. Links in a task open in the remote Firefox. To allow other sites, run sudo cka-firefox-mode open in the terminal.

Timer

The timer is 2 hours. It keeps running if you switch tabs or reload the page. Use “Start exam” to start or reset it.

Local lab workflow

Each task directory contains setup.sh, question.md, validate.sh and cleanup.sh. Open the “Lab helper” in the question panel to copy the commands.
